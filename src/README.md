# Source Code of KVerus

This directory contains the source code of KVerus, with the following structure:

- `preprocessor/`: The preprocessor module, used to preprocess the source code and extract metadata.
- `comprehender/`: The comprehender module, used to comprehend the documents and create knowledge bases.
- `prover/`: The prover module, used to generate the proof code.
- `prover/`: The refiner modules, used to refine the proof code.
- `llm/`: The LLM interaction related code.
- `prompt/`: All the prompt templates.
- `tests/`: Tests during the development.
- `configer/`: Configuration management in KVerus CLI. 
- `analyzer/`: Analyze verus error message and generate report for failing reason.
- `utils.py`: Some global utility functions.
- `vars.py`: Some global variables.
